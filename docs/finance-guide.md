# คู่มือใช้งาน "งานการเงิน" — Easy Ekkasan

สำหรับครูการเงิน/เจ้าหน้าที่การเงินของโรงเรียน · ปรับปรุง 13 ก.ย. 2569

---

## ลำดับงานที่ควรทำ (ทำครั้งเดียวตอนเริ่ม)

### 1. ตั้งบัญชี/ประเภทเงิน — เมนู "ทะเบียนคุมเงิน"

เพิ่มบัญชีให้ครบทุกประเภทเงินที่โรงเรียนมี เช่น

- เงินอุดหนุนรายหัว (ค่าจัดการเรียนการสอน)
- เงินอุดหนุนอาหารกลางวัน
- เงินรายได้สถานศึกษา
- เงินประกันสัญญา

แต่ละบัญชีต้องกรอก 3 อย่าง

| ช่อง | ใส่อะไร | มีผลกับอะไร |
|---|---|---|
| **ยอดยกมา** | เงินคงเหลือต้นปีงบ | ยอดตั้งต้นของสมุดเงินสด |
| **เก็บเงินไว้ที่** | เงินสด / เงินฝากธนาคาร / ฝากส่วนราชการผู้เบิก | รายงานเงินคงเหลือประจำวัน |
| **ประเภทเงินตามงบ** | เงินงบประมาณ / นอกงบประมาณ / รายได้แผ่นดิน | สมุดเงินสดแบบราชการ |

> ถ้ากรอก "ประเภทเงินตามงบ" ผิด สมุดเงินสดจะลงคอลัมน์ผิด แก้ทีหลังได้แต่ต้องออกเอกสารใหม่

---

## งานประจำวัน

### 2. บันทึกรับ-จ่ายเงิน

เข้าบัญชีที่ต้องการ → กรอกวันที่ · รับหรือจ่าย · จำนวนเงิน · หมวด · เลขที่เอกสารอ้างอิง

**ทางลัด:** ถ้าจ่ายเงินตามบันทึกขอเบิกจ่าย ไม่ต้องลงรายการเอง ระบบตัดยอดให้ตอนกด "ลงบัญชี"

### 3. บันทึกขอเบิกจ่าย — เมนู "บันทึกขอเบิกจ่าย"

กรอกเรื่อง ผู้รับเงิน จำนวนเงิน แล้วระบบออกบันทึกขออนุมัติเบิกจ่ายเป็น Word ให้

ช่องที่ต้องระวัง
- **VAT** ใส่เฉพาะกรณีผู้ขายจดทะเบียนภาษีมูลค่าเพิ่ม
- **หัก ภาษี ณ ที่จ่าย** ปกติงานจ้าง 1% ของยอดก่อน VAT — **กรอกช่องนี้แล้วจะมีปุ่มพิมพ์หนังสือรับรอง 50 ทวิ ให้ผู้รับจ้าง**
- **ค่าปรับ** กรณีส่งงานช้า

กด **"ลงบัญชี"** เมื่ออนุมัติแล้ว ระบบจะตัดยอดในบัญชีให้อัตโนมัติ ไม่ต้องลงรายการซ้ำ

### 4. ทะเบียนใบเสร็จ / ใบสำคัญรับเงิน

บันทึกเลขที่ใบเสร็จทุกใบที่ออก แล้วกดปุ่ม **"ใบสำคัญรับเงิน"** เพื่อพิมพ์ใบให้ผู้รับเงินลงชื่อ (ใช้กรณีผู้รับเงินออกใบเสร็จให้ไม่ได้)

### 5. ทะเบียนคุมเช็ค — เมนู "ทะเบียนคุมเช็ค"

ทุกครั้งที่สั่งจ่ายเช็ค ให้บันทึก: วันที่ · เลขที่เช็ค · ธนาคาร · จ่ายให้ · จำนวนเงิน

**สำคัญ:** เมื่อรู้ว่าผู้รับนำเช็คไปขึ้นเงินแล้ว (ดูจาก statement) ให้กดปุ่ม **"ขึ้นเงินแล้ว"** เพราะเช็คที่ยังไม่กดจะถูกนับเป็นเช็คคงค้างในงบกระทบยอดเดือนถัดไป

---

## งานประจำเดือน

### 6. งบกระทบยอดเงินฝากธนาคาร — เมนู "งบกระทบยอดธนาคาร"

ทำทุกสิ้นเดือนหลังได้ statement จากธนาคาร

1. เลือกบัญชีธนาคาร
2. กรอก **ยอดตาม statement** (ยอดที่ธนาคารแจ้ง)
3. ระบบเติมให้อัตโนมัติ 2 ช่อง — ยอดตามบัญชีของโรงเรียน และเช็คคงค้าง
4. กรอกเพิ่มถ้ามี: เงินฝากระหว่างทาง · ดอกเบี้ยที่ยังไม่ลงบัญชี · ค่าธรรมเนียมธนาคาร
5. กดบันทึก → ระบบบอกว่า **"ตรงกัน"** หรือ **ต่างกันเท่าไร**

สูตรที่ระบบใช้

```
ยอดตาม statement
  + เงินฝากระหว่างทาง   (ฝากแล้วธนาคารยังไม่บันทึก)
  + ดอกเบี้ยที่ยังไม่ลงบัญชี
  − เช็คที่ผู้รับยังไม่นำไปขึ้นเงิน
  − ค่าธรรมเนียมธนาคารที่ยังไม่ลงบัญชี
  = ต้องเท่ากับ ยอดคงเหลือตามบัญชีของโรงเรียน
```

**ถ้ายอดไม่ตรง** แปลว่ามีรายการที่ยังไม่ได้ลงบัญชี หรือลงผิด ให้ไล่ดูรายการเดือนนั้นก่อนปิดเดือน

### 7. รายงานเงินคงเหลือประจำวัน

ออกทุกวันทำการที่มีการรับ-จ่ายเงิน มีช่องลงนามคณะกรรมการเก็บรักษาเงิน 3 คน

## งานเมื่อมีคนยืมเงิน

### 8. เงินยืม — เมนู "เงินยืม"

**ตอนให้ยืม**
1. กรอก: เลขที่สัญญา · วันที่ยืม · วันครบกำหนดส่งใช้ · ผู้ยืม · จำนวนเงิน · วัตถุประสงค์
2. กด **"สัญญา 8500"** พิมพ์สัญญาการยืมเงินตามแบบกรมบัญชีกลาง (หน้า = สัญญา · หลัง = รายการส่งใช้)
3. ให้ผู้ยืมลงชื่อ เสนอ ผอ. อนุมัติ แล้วจ่ายเงิน

**ตอนคืนเงิน**

กดปุ่ม **"ส่งใช้"** ที่แถวนั้น → กรอกวันที่ · ส่งใช้เป็นเงินสดหรือใบสำคัญ · จำนวนเงิน · ใบรับเลขที่

ส่งใช้ได้หลายครั้ง ระบบคิดยอดคงค้างให้เอง แถวที่ยังค้างจะขึ้นพื้นสีส้ม พอส่งใช้ครบจะขึ้น "ส่งใช้ครบแล้ว"

**ตอนตรวจสอบ** กด "พิมพ์ทะเบียนคุม" ได้ทะเบียนคุมลูกหนี้เงินยืมทั้งปี

> ⚠️ ระเบียบกำหนดให้ส่งใช้ภายใน 15 วันนับแต่วันที่ได้รับเงิน (ค่าเริ่มต้นในระบบ) ถ้าเกินกำหนดให้หักจากเงินเดือนได้ตามที่ระบุในสัญญา

## งานส่งเขตพื้นที่ฯ

### 9. รายงานรายไตรมาส — เมนู "รายงานรายไตรมาส"

เลือกไตรมาส ระบบสรุปยอดยกมา · รับในไตรมาส · จ่ายในไตรมาส · คงเหลือ แยกตามบัญชี

| ไตรมาส | เดือน |
|---|---|
| 1 | ตุลาคม – ธันวาคม |
| 2 | มกราคม – มีนาคม |
| 3 | เมษายน – มิถุนายน |
| 4 | กรกฎาคม – กันยายน |

### 10. รายงานแบบ สตง. — เมนู "รายงานแบบ สตง."

รวมชุดเอกสารที่ผู้ตรวจขอบ่อย: สมุดเงินสด · บัญชีแยกประเภท · รายงานเงินคงเหลือ ออกได้ทั้ง Word และ Excel

## สรุปว่าเอกสารไหนอยู่เมนูไหน

| เอกสาร | เมนู | ความถี่ |
|---|---|---|
| บันทึกขออนุมัติเบิกจ่าย | บันทึกขอเบิกจ่าย | ทุกครั้งที่จ่าย |
| หนังสือรับรองหักภาษี 50 ทวิ | บันทึกขอเบิกจ่าย (ในบันทึกที่มีหักภาษี) | ทุกครั้งที่หักภาษี |
| ใบสำคัญรับเงิน | ทะเบียนใบเสร็จ | ตามการรับเงิน |
| สัญญาการยืมเงิน แบบ 8500 | เงินยืม | ทุกครั้งที่ให้ยืม |
| ทะเบียนคุมลูกหนี้เงินยืม | เงินยืม | สิ้นปีงบ / เมื่อถูกตรวจ |
| ทะเบียนคุมการจ่ายเช็ค | ทะเบียนคุมเช็ค | สิ้นปีงบ / เมื่อถูกตรวจ |
| งบกระทบยอดเงินฝากธนาคาร | งบกระทบยอดธนาคาร | ทุกสิ้นเดือน |
| รายงานเงินคงเหลือประจำวัน | เงินคงเหลือประจำวัน | ทุกวันที่มีรับ-จ่าย |
| สมุดเงินสด / บัญชีแยกประเภท | สมุดเงินสด / รายงานแบบ สตง. | ทุกเดือน + สิ้นปีงบ |
| รายงานรายไตรมาส | รายงานรายไตรมาส | ทุก 3 เดือน |

## ข้อควรระวัง

1. **กรอกประเภทเงินให้ถูกตั้งแต่ตั้งบัญชี** เพราะสมุดเงินสดแยกคอลัมน์ตามนี้
2. **อย่าลงรายการซ้ำ** ถ้าใช้บันทึกขอเบิกจ่ายแล้วกด "ลงบัญชี" ระบบตัดยอดให้แล้ว
3. **ติ๊กเช็คที่ขึ้นเงินแล้วทุกเดือน** ไม่งั้นงบกระทบยอดจะเพี้ยน
4. **เงินยืมต้องตามให้ส่งใช้ตามกำหนด** ทะเบียนคุมลูกหนี้เงินยืมคือเอกสารที่ สตง. ขอดูบ่อย
5. **ดาวน์โหลดไฟล์สำรองเก็บไว้สม่ำเสมอ** ที่ ตั้งค่าโรงเรียน → สำรอง/กู้คืนข้อมูล
