# ปฏิทินวันเรียนร่วม

- เปิดที่ ตั้งค่าโรงเรียน → ปฏิทินการศึกษา ใช้ข้อมูลเดิมชุดเดียวกับงานวิชาการ แยกตามปีการศึกษา
- หน้ารอบจัดจ้างอาหารกลางวันมีปุ่ม ตั้งค่าปฏิทินวันเรียน กลับด้วยปุ่มด้านบนได้ ข้อมูลฟอร์มที่ยังไม่บันทึกเก็บเฉพาะในแท็บเดิมชั่วคราว 4 ชั่วโมง แยกตามผู้ใช้และโรงเรียน
- เพิ่มวันหยุดพิเศษ หรือคลิกปิดวันที่ในปฏิทิน แล้วบันทึก วันเสาร์ที่คลิกเปิดจะนับเป็นวันเรียนชดเชยได้
- เดือนที่บันทึกแล้วใช้วันตามที่โรงเรียนเลือก เดือนที่ยังไม่บันทึกใช้จันทร์–ศุกร์ ลบวันหยุดและวันนอกภาคเรียน
- เพิ่มวันหยุดจะปิดเฉพาะวันที่เพิ่มในเดือนที่บันทึกไว้ ไม่ล้างวันชดเชยอื่น การลบวันหยุดไม่เปิดวันนั้นเอง ต้องตรวจและคลิกเปิดก่อนบันทึก
- รอบและงวดที่สร้างใหม่คำนวณจากปฏิทินร่วม เมื่อกำหนดวันเริ่มและวันสิ้นสุด จะนับจำนวนวันเรียนในช่วงนั้น

## งวดเดิมหลังแก้ปฏิทิน

ในหน้าจัดการงวด กด **แก้วันในงวดหลังปรับปฏิทิน** ดูวันเดิม วันใหม่ วันที่ข้าม และวันที่เพิ่ม แล้วกดยืนยัน

ระบบคงจำนวนวันและวงเงินเดิม เลื่อนงวดร่างต่อกันให้ครบวัน ไม่แก้รายการส่งมอบ/ตรวจรับ/จ่ายแล้วหรือรายการที่มีบัญชีจ่าย ไม่ลบยอดนักเรียนที่เคยบันทึก ถ้าวันที่ถูกตัดมียอดนักเรียน จะไม่อนุญาตให้ยืนยัน หากเลื่อนเลยวันสิ้นสุดรอบต้องตรวจและแก้ช่วงรอบก่อน

ตัวอย่าง 11–15 ธ.ค. จำนวน 3 วัน เมื่อปิด 15 ธ.ค. จะเป็น 11–16 ธ.ค. งวดถัดไปเริ่ม 17 ธ.ค. ทั้งนี้ขึ้นกับวันเรียนที่เลือกไว้จริง

## การอัปเดตและข้อมูลย้อนหลัง

เพิ่มคอลัมน์ calendar_dates แบบ nullable ใน LunchHireRound และ LunchInstallment ด้วย migration ปกติ ค่า NULL หมายถึงรายการเก่าที่ต้องคงกฎนับวันเดิมจนกว่าจะยืนยันปรับ เก็บวันจริงของรายการใหม่และรายการที่ยืนยันแล้ว ไม่คำนวณยอดเอกสารย้อนหลังใหม่เพราะแก้ปฏิทินเพียงอย่างเดียว

การเปลี่ยนชุดวันในรายการมีผลต่อข้อมูลที่ใช้ตรวจการอนุมัติ แม้วันเริ่ม–สิ้นสุดเหมือนเดิม ต้องตรวจและส่งอนุมัติใหม่ ประวัติอนุมัติของรายการเก่าที่ไม่ได้แก้ยังใช้ได้ตามเดิม

สิทธิ์: เจ้าของและเจ้าหน้าที่อาหารกลางวันแก้ได้ เจ้าหน้าที่วิชาการตามสิทธิ์เดิม ครูผู้สอนและผู้อำนวยการดูอย่างเดียว การตั้งค่าถูกแยกตามโรงเรียนด้วยฐานข้อมูลเดิม

หน้าตรวจวันที่แยกสีส้มสำหรับวันเดิมและสีฟ้าสำหรับวันตามปฏิทิน วันที่เปลี่ยนเป็นตัวหนาพร้อมขีดเส้นใต้ ถ้างวดเลื่อนเลยวันสิ้นสุดรอบ จะแสดงการ์ดเตือนพร้อมวันสิ้นสุดเดิม วันสิ้นสุดที่งวดต้องใช้ และปุ่มแก้วันสิ้นสุดรอบจัดจ้างที่เด่นขึ้น ระบบยังไม่ยอมให้ยืนยันจนกว่าจะแก้ช่วงรอบให้ครอบคลุมและผ่านเงื่อนไขอื่นครบ
