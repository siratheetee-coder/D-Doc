# หนังสือรับและการติดตามผล

## ทางเข้าหน้าใช้งาน

- ธุรการ: ทะเบียนหนังสือรับ → ติดตามการรับทราบและผลการดำเนินงาน
- ผอ.: หน้าหลัก → ติดตามหนังสือและงานที่มอบหมาย หรือจากกล่องรออนุมัติ
- ครู: หนังสือถึงฉัน → เปิดหนังสือ → รับทราบ / รายงานผลการดำเนินงาน

## วิธีใช้

1. ลงทะเบียนหนังสือรับและแนบไฟล์ได้ตามเดิม
2. เลือกผู้รับ แล้วเลือกว่าจะ “แจ้งเพื่อทราบ” หรือ “มอบหมายให้ดำเนินการ”
3. ถ้ามอบหมาย ให้ระบุงาน ผู้รับผิดชอบ (ต้องเป็นผู้รับหนังสือด้วย) และกำหนดส่งถ้ามี
4. เสนอ ผอ. ให้ตรวจหรือปรับผู้รับผิดชอบก่อนสั่งการ หรือธุรการเวียนตรงได้ตามสิทธิ์เดิม
5. ครูกดรับทราบ และถ้ามีงานที่มอบหมาย ให้เขียนรายงานผลพร้อมแนบ PDF, DOCX, JPG หรือ PNG ได้ไม่เกิน 10 MB
6. ผอ. ตรวจผล → เสร็จสิ้น หรือระบุสิ่งที่ต้องปรับแล้วส่งกลับให้แก้ไข
7. รายงานครั้งเก่ายังอยู่ในประวัติเมื่อครูส่งฉบับแก้ไข

ผู้ที่ไม่มีบัญชีครูยังให้ธุรการบันทึกรับทราบแทนได้ตามเดิม แต่การส่งรายงานในระบบต้องมีบัญชีที่ผูกกับบุคลากรคนนั้น

## ความหมายของสถานะ

- รับทราบ: ครูกดรับทราบ หรือธุรการบันทึกแทน แยกจากสถานะงานและการส่งอีเมล
- ยังไม่รายงานผล: ได้รับมอบหมายแต่ยังไม่ได้ส่ง
- รอตรวจผล: ครูส่งรายงานแล้ว
- ให้แก้ไขรายงาน: ผู้ตรวจระบุสิ่งที่ต้องปรับ ครูส่งใหม่ได้
- เสร็จสิ้น: ผู้ตรวจยืนยันผลแล้ว
- เกินกำหนด: พ้นวันกำหนดส่งและยังไม่ส่งรายงาน หรืออยู่ระหว่างแก้ไขรายงาน

ผอ. กดส่งอีเมลเตือนเฉพาะคนที่ยังไม่รับทราบได้ ไม่มีการส่งเตือนตามเวลาอัตโนมัติ

## การอัปเดตและข้อมูลเดิม

- สร้างตาราง `letter_task` และ `letter_task_report` อัตโนมัติเมื่อเปิดฐานข้อมูลโรงเรียนหลังอัปเดต
- หนังสือและการรับทราบเดิมไม่ถูกเปลี่ยนเป็นงานที่ต้องรายงานผล
- ไฟล์รายงานเก็บใน `data/schools/<id>/letter_reports/` เข้าผ่านเส้นทางที่ตรวจสิทธิ์เท่านั้น
- ระบบสำรองข้อมูลส่วนกลางรวมโฟลเดอร์นี้อยู่แล้ว
- การส่งรายงานและตรวจผลตรวจเลขรุ่นข้อมูล เพื่อกันการกดซ้ำหรือหน้าเก่าเขียนทับผลใหม่

## ทดสอบก่อนใช้งานจริง

1. แนบหนังสือที่มีเลขรับ แล้วลองเวียนตรงและผ่าน ผอ. ต้องไม่พบ Error 500
2. ไม่เลือกผู้รับแล้วกดสั่งการ ต้องเตือนและคงหนังสือไว้ในคิว
3. ลงทะเบียนปีเก่าแล้วต้องกลับทะเบียนปีเดิม
4. เลือกครู 2 คน แต่มอบหมาย 1 คน อีกคนต้องมีเฉพาะปุ่มรับทราบ
5. ส่งรายงาน → ส่งกลับ → ส่งใหม่ → ตรวจเสร็จสิ้น ตรวจประวัติแต่ละครั้ง
6. บัญชีครูอีกคนและโรงเรียนอื่นต้องเปิดไฟล์รายงานที่ไม่ได้รับสิทธิ์ไม่ได้
