# ทะเบียนคุมสัญญา

หน้า `/procurement/contracts` ใช้ติดตามสัญญาและกำหนดส่งมอบ โดยไม่สร้างรายการรับจ่ายเงิน

- เลือกปีงบประมาณ แล้วกดนำเข้าจากพัสดุหรืออาหารกลางวัน
- หน้าตรวจรายการอยู่ในหน้าเดิม แสดงรายการใหม่ ข้อมูลที่เปลี่ยน รายการที่มีแล้ว และรายการที่ต้องตรวจสอบ
- ต้องเลือกรายการก่อนยืนยัน ระบบตรวจข้อมูลซ้ำอีกครั้งขณะบันทึก หากต้นทางเปลี่ยนต้องเปิดตรวจรายการใหม่
- อัปเดตเฉพาะข้อมูลสัญญาที่แสดงในรายการตรวจสอบ ข้อมูลประกันและหมายเหตุยังอยู่
- งานอาหารกลางวันที่ผูกใบสั่งเดียวกับเรื่องพัสดุ ใช้รายการสัญญาเดียวกัน ปีงบใช้ปีของเรื่องพัสดุที่ผูก หรือวันที่ใบสั่งสำหรับรอบที่ไม่ผูกเรื่องพัสดุ ไม่ใช้ปีการศึกษาแทนปีงบ
- รายการเดิมซ้ำหรืออยู่คนละปีไม่ถูกลบหรือย้ายอัตโนมัติ มีลิงก์ให้ตรวจรายการเดิมก่อน
- แก้ไขผ่านปุ่มในแต่ละรายการ บันทึกทั้งหมดส่งเฉพาะรายการที่แก้ หากบางรายการไม่สำเร็จจะเก็บค่าที่กรอกไว้ให้ลองใหม่
- การแก้ไขที่ไม่ได้ส่งช่องวันที่มา ไม่ล้างวันที่เดิม วันที่ผิด วงเงินติดลบ หรือกำหนดส่งมอบก่อนวันทำสัญญา/เริ่มงานจะแจ้งให้แก้
- แจ้งเตือนส่งมอบก่อนครบกำหนด 15 วันและเมื่อเกินกำหนด หยุดหลังส่งมอบ ตรวจรับ จ่ายแล้ว หรือสิ้นสุด หน้าและกระดิ่งใช้เงื่อนไขเดียวกัน
- ค้นหาและกรองสถานะได้ทันที ป้ายเวลาและจำนวนในหน้านี้เปลี่ยนทันทีหลังบันทึก

ไม่มีการเปลี่ยนโครงสร้างฐานข้อมูลหรือแก้ประวัติสัญญาเดิมขณะอัปเดตโปรแกรม
