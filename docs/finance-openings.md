# ยอดยกมารายหมวดและเงินคงเหลือจริง

เปิดทะเบียนคุมเงิน เลือกบัญชีและปีงบ แล้วกรอกส่วนยอดยกมาต้นปีงบ ยอดรวมรายหมวดต้องเท่ากับยอดบัญชี หมวดแม่กรอกเฉพาะเงินของตัวเอง ไม่รวมลูก ระบบเตือนผลต่างก่อนบันทึกและตรวจซ้ำฝั่งเซิร์ฟเวอร์ มี token ป้องกันหน้าเก่าทับยอดใหม่

AccountItem.opening_balance แยกจาก budget โดยหมวดเป็นรายปีงบอยู่แล้ว ฐานข้อมูลเดิมเพิ่มคอลัมน์ค่าเริ่มต้น 0 ไม่เดายอดเงินจากงบเดิม ผู้ดูแลต้องกรอกยอดคงเหลือจริงเมื่อเริ่มใช้ ยอดบัญชีเดิมคงอยู่และแสดงส่วนที่ยังไม่แยกหมวดในรายงานเงินคงเหลือและชุดทะเบียนคุม

เงินคงเหลือ = ยอดยกมา + รับจริง - จ่ายจริง งบที่ตั้งไว้ใช้แสดงแผนเท่านั้น สูตรนี้ใช้ในหน้าบัญชี หน้ารายหมวด รายงานเงินคงเหลือประจำวัน Word ทะเบียนคุม และ Excel รายหมวด ยอดหมวดแม่รวมเงินตัวเองและลูกครั้งเดียว

การยกยอดข้ามปีนำยอดคงเหลือจริงเฉพาะหมวดไปเป็นยอดยกมาปีถัดไป จับคู่ชื่อภายใต้หมวดแม่เดียวกัน หากยังไม่มีจะสร้างโดยงบเป็น 0 ไม่เปลี่ยนงบปลายทางเดิม บล็อกชื่อซ้ำและหมวดปลายทางที่มียอดแต่ไม่มีคู่ต้นทาง การยกซ้ำปรับยอดเดิม ไม่เพิ่มรายการรับและไม่ลบปีเก่า
