# หน้าหลักตามบทบาท

เจ้าของโรงเรียนเห็นสรุปสถานะอนุมัติเมื่อเปิด approval_on โดยนับเฉพาะแถวล่าสุดของแต่ละชนิดและเรื่อง ไม่รวมประวัติส่งซ้ำ อนุมัติแล้วแสดงย้อนหลัง 7 วัน เรื่องที่แก้หลังอนุมัติอยู่ในกลุ่มต้องส่งใหม่ นับเป็นรายการอนุมัติ เพราะเรื่องจัดซื้อมีหลายขั้น แต่ละการ์ดเปิดรายการตามสถานะได้

หนังสือรับนับเป็นจำนวนเรื่อง ไม่ใช่จำนวนผู้รับ รวมงานค้างข้ามปี รอ ผอ. สั่งการ = route_status director หนังสือที่ยังมีผู้ไม่รับทราบ = sent และมี recipient ไม่ ack งานเลยกำหนด = งาน pending/returned ที่เลยวันกำหนด รายการที่ยังไม่เวียนจะแสดงในงานต้องจัดการเมื่อมีผู้รับที่เตรียมไว้แล้ว ระบบเดิมที่ ผอ. สั่งแล้วส่งเวียนทันทีไม่มีสถานะรอส่งต่อ จึงไม่สร้างยอดสมมติขึ้นเอง คลิกแต่ละการ์ดเข้ารายการเฉพาะกลุ่มและเปิดเรื่องเพื่อติดตามรายบุคคลได้

งานพัสดุ การเงิน และบุคคลอื่นในหน้าหลักใช้การแจ้งเตือนตามสิทธิ์จาก nav_alerts ที่มีอยู่ ย่อการ์ดเข้าแต่ละฝ่ายและเก็บสิทธิ์เดิม ย่อการตั้งค่าปี/ขั้นเริ่มต้นไว้ในส่วนเปิดปิดได้

ครูที่ผูก person_id และไม่ใช่เจ้าของเห็นหน้าหลักส่วนตัวที่ / และเข้าหน้านี้หลังล็อกอินตามปกติ หากมี next ที่ปลอดภัยยังไป next เหมือนเดิม หน้า /academic ยังใช้งานเดิมได้ มีทางลัดและเมนูหน้าหลักของฉัน

ครูเห็นเฉพาะ LetterRecipient ของตนเองที่หนังสือส่งจริงแล้ว แสดงจำนวนรอรับทราบ งานรอรายงาน และงานเกินกำหนดแยกกัน งานที่ ack แล้วแต่ยังไม่รายงานยังค้าง ส่วนงาน submitted/done ไม่ถูกนับว่ารอรายงาน มีทางลัดเปิดเรื่อง ไม่มีการรับทราบหรือตรวจงานอัตโนมัติ

ผลอนุมัติเอกสารในหน้าครูนับเฉพาะ sent_uid ของตน หรือรายการเก่าที่ sent_uid ว่างและ sent_pid ตรงบุคลากร ไม่แสดงผลรวมของโรงเรียน การแจ้งเตือนส่วนตัวอื่นใช้กระดิ่งเดิมของบุคลากร บัญชีเจ้าหน้าที่ที่ไม่ผูกบุคลากรใช้หน้าฝ่ายตามสิทธิ์ โดยสรุปอนุมัติเฉพาะที่ตนส่ง ผอ. ยังคงหน้าหลัก ผอ. เดิม

อัปเดตระบบเป็นบันทึกคัดเลือกใน app/services/home_dashboard.py (UPDATES) แสดงสองรายการล่าสุดและอ่านทั้งหมดที่ /system-updates ยังไม่มีตัวแก้ข้อความอัปเดตในคอนโซล

ไม่เพิ่มคอลัมน์หรือเปลี่ยนข้อมูลเดิม ทดสอบด้วยฐานข้อมูลตัวอย่างแยกจากโรงเรียนจริง รวมถึงสิทธิ์ครู หนังสือไม่ส่งจริง การรับทราบกับรายงานที่เป็นคนละขั้น สถานะล่าสุดของการอนุมัติ และการเปลี่ยนยอดหลังอนุมัติ ตรวจหน้าจอ desktop/mobile ด้วยข้อมูลสมมติ
