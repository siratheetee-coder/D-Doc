# งบประมาณที่ใช้จัดทำแผน

1. เปิด โครงการ/แผนงบ แล้วเลือกปีและ «งบประมาณที่ใช้จัดทำแผน»
2. บันทึกรูปแบบปีงบประมาณ (1 ต.ค.–30 ก.ย.) หรือปีการศึกษา (เริ่มต้น 1 พ.ค.–30 เม.ย. ปรับวันได้)
3. ตรวจยอดยกมาจากทะเบียนคุม แล้วเลือกรายการที่จะใช้ เงินแต่ละหมวดใช้ยอดของตัวเอง ไม่รวมลูกซ้ำ
4. ยืนยันผลคำนวณเงินอุดหนุนและจับคู่หมวดที่หน้าคำนวณเงินอุดหนุน จากนั้นกลับมาตรวจและนำยอดเข้าแผน
5. เปิดแต่ละโครงการแล้วติ๊กบัญชีเงินที่โครงการใช้ได้ เลือกหลายบัญชีได้โดยไม่กรอกจำนวนเงิน ไม่กันหรือตัดเงินจากกองกลาง
6. ปุ่มบันทึกจ่ายในโครงการเลือกบัญชี หมวด และโครงการไว้ให้ ตรวจปีงบก่อนบันทึก ห้ามลงซ้ำรายการที่มีอยู่แล้ว

การนำเข้าเป็นการบันทึกวงเงินวางแผน ไม่สร้างรายการรับจริง ไม่เปลี่ยนยอดบัญชีหรืองบโครงการเดิม การนำรายการเดิมเข้าซ้ำอัปเดตยอดเดิมไม่บวกเพิ่ม เมื่อยอดต้นทางเปลี่ยนต้องตรวจและยืนยันใหม่ การเชื่อมบัญชียังคงอยู่เมื่อยอดเงินเปลี่ยน

ยอดยกมาของแผนปีการศึกษาใช้เงินคงเหลือก่อนวันเริ่มแผน ส่วนปีงบใช้ยอดยกมาต้นปี หากได้รับเงินอุดหนุนของเทอมนั้นก่อนวันเริ่มแผน ต้องเชื่อมรายการรับในหน้าคำนวณเงินอุดหนุนก่อน ระบบจึงจะหักเงินรับส่วนนี้ออกจากยอดใหม่เพื่อไม่นับซ้ำกับยอดยกมา ระบบไม่เดาความสัมพันธ์จากชื่อบัญชี

ปีการศึกษาใช้ฉบับยืนยันทั้งสองเทอมของปีนั้น ปีงบใช้ฉบับที่มีปีงบตรงกัน ไม่อนุญาตให้นำเงินก้อนเดิมไปใช้หลายแผนหรือมีแผนที่นำเข้างบแล้วในช่วงวันที่ซ้อนกัน รายการเงินอื่นที่กรอกเองต้องตรวจว่าไม่ซ้ำยอดยกมาหรือเงินอุดหนุน

«จ่ายจริงตามทะเบียนคุมเงิน» รวมรายการจ่ายที่ผูกกับโครงการโดยตรงหรือผ่านบันทึกเบิกจ่ายเพียงครั้งเดียว ส่วน «ใช้ไป» เดิมยังรวมวงเงินจัดซื้อและบันทึกเบิกตามพฤติกรรมเดิม

ตารางใหม่ PlanBudget / PlanFunding / ProjectFunding สร้างด้วย create_all ตามระบบเดิม ไม่ปรับข้อมูลรับจ่ายย้อนหลัง ทดสอบใน tests/test_plan_funding.py รวมถึงการนำซ้ำ การเชื่อมหลายบัญชีโดยไม่กันเงิน การเปลี่ยนยอด วันที่ไทย การรับก่อนเริ่มแผน และเส้นทาง HTTP


## Project/account links (November 2026)

ProjectFunding now records a relationship only. Existing rows retain their historical
amount values for compatibility, but those values never reserve money or constrain
project budgets. New links store amount=0. No migration or financial transaction is
needed; existing projects retain their linked accounts automatically.

The project card shows current ledger balances for linked AccountItems; PlanFunding
amounts remain planning snapshots. A 20,000 project linked to a 59,000 account leaves
59,000 in the account. A real 3,000 payment reduces it to 56,000. Payment splits are
specified in the existing payment flow, not in the project source selector.
